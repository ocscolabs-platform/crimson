# Phase 2 — Acceptance Criteria

Phase 2 is complete when the owner can approve the visual and content direction as a reliable input to public website implementation.

## Required outcomes

- [ ] The working positioning and voice rules are approved.
- [ ] Homepage, Services, Work, About, and Contact content briefs are approved.
- [ ] The provisional color, typography, spacing, radius, and interaction tokens are approved or revised.
- [ ] The owner confirms which existing brand assets may be reused in Crimson.
- [ ] The owner identifies the launch content required for the first implementation slice.
- [ ] At least one case study is selected or explicitly deferred.
- [ ] Contact ownership and response expectations are defined.
- [ ] No public-facing claim is planned without an evidence or approval path.
- [ ] The boundary between design direction and implementation is understood.

## Quality constraints

- No public website routes are implemented in Phase 2.
- No CMS, CRM, authentication, database, or storage functionality is implemented in Phase 2.
- No production credentials, client data, or unapproved brand assets are added to the repository.
- Visual direction remains consistent with the existing OCSCO brand reference unless the owner explicitly changes it.
- Accessibility, responsive behavior, reduced motion, and content readability are part of the design definition, not post-launch cleanup.

## Phase exit review

The owner should review:

1. [`CONTENT-BRIEFS.md`](./CONTENT-BRIEFS.md)
2. [`VISUAL-DESIGN-DIRECTION.md`](./VISUAL-DESIGN-DIRECTION.md)
3. This acceptance checklist

When approved, the next phase can implement the first public route using the agreed content and visual system.
