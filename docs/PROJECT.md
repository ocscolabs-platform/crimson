# Project 0 — Product Vision

OCSCO is replacing its existing WordPress website with a custom platform built for long-term ownership and extension. Project Crimson is the repository and working name for this platform.

The finished platform is intended to serve four connected purposes:

- A polished public OCSCO website.
- An internal platform that supports a custom CMS.
- A first-party Insights publishing system managed by the CMS.
- A custom CRM for inquiries and relationship management.

The CMS will give OCSCO control over structured website and Insights content and publishing workflows. The CRM will support business operations and relationship management. They are planned as integrated parts of the same OCSCO platform, not unrelated products. Insights content will reuse the CMS authentication, roles, revisions, media, SEO, and published-only public boundary rather than introducing a third-party CMS.

OCSCO wants the platform to demonstrate its ability to deliver branding, website design and development, custom CMS systems, CRM and business tools, and custom web applications. Project 0 is intended to become OCSCO's first flagship case study.

Phase 0 established the repository and deployment foundation. Phase 1 established the public sitemap, content model, audiences, and acceptance criteria. Phase 2 established content and visual design direction. Phase 3 delivered the public website and contact workflow. Phase 4 delivered the approved CMS slices. Phase 5 Full Page Content editing is complete and staging-verified through Work Packages A and B; the Production release/promotion gate remains deferred. Phase 6 Insights Batch 6A is now in progress on a feature branch targeting `staging`; Batch 6B, the composer, media delivery, and public Insights routes remain deferred. Phase 7 will define and build the CRM, and Phase 8 covers future hardening and reusable-platform work. See [`MASTER-PLAN.md`](./MASTER-PLAN.md) for the canonical phase order and release gates.
