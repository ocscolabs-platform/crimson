# Project 0 — Product Vision

OCSCO is replacing its existing WordPress website with a custom platform built for long-term ownership and extension. Project Crimson is the repository and working name for this platform.

The finished platform is intended to serve four connected purposes:

- A polished public OCSCO website.
- An internal platform that supports a custom CMS.
- A first-party Blog / Insights publishing system managed by the CMS.
- A custom CRM for inquiries and relationship management.

The CMS will give OCSCO control over structured website and Blog / Insights content and publishing workflows. The CRM will support business operations and relationship management. They are planned as integrated parts of the same OCSCO platform, not unrelated products. Blog content will reuse the CMS authentication, roles, revisions, media, SEO, and published-only public boundary rather than introducing a third-party CMS.

OCSCO wants the platform to demonstrate its ability to deliver branding, website design and development, custom CMS systems, CRM and business tools, and custom web applications. Project 0 is intended to become OCSCO's first flagship case study.

Phase 0 established the repository and deployment foundation. Phase 1 established the public sitemap, content model, audiences, and acceptance criteria. Phase 2 established content and visual design direction. Phase 3 delivered the public website and contact workflow. Phase 4 delivered the approved CMS slices; its staging-to-main code merge is complete and Phase 4C now verifies the post-merge Production baseline. Phase 5 will complete page-body content editing, Phase 6 will add Blog / Insights on the shared CMS foundation, and Phase 7 will define and build the CRM.
